# AziLamp IR — Прошивка с ИК-пультом

Альтернативная прошивка для лампы AziLamp. **Wi-Fi полностью отключён**: лампа не создаёт сеть, веб-панель недоступна. Управление осуществляется через **ИК-пульт** и штатную **сенсорную кнопку**.

Часы, погода и E1.31 отключены. Все эффекты, яркость и сохранённые настройки (EEPROM) остаются прежними.

## Состав релиза

| Файл | Описание |
|---|---|
| `AziLamp_IR.bin` | Прошивка ESP8266 с поддержкой ИК-приёмника |
| `flash_IR.bat` | Скрипт прошивки для Windows |
| `INSTRUKTsIYa.md` | Подробная инструкция по подключению и диагностике |

## Подключение ИК-приёмника KY-022

> ⚠️ **Обесточьте лампу перед подключением!** Неправильная полярность может сжечь модуль.

| Контакт KY-022 | Пин Wemos D1 mini | Примечание |
|:---:|:---:|---|
| **S** (сигнал) | **D5** | GPIO14 |
| **+** | **3V3** | Только 3.3 В, **не 5 В!** |
| **-** | **GND** | Общий провод |

Порядок контактов на разных модулях отличается — **всегда сверяйтесь с надписями на плате**. Пины D2 (лента) и D4 (кнопка) уже заняты, их не трогайте.

## Прошивка

### Windows
```cmd
flash_IR.bat COM3
```
Замените `COM3` на ваш порт (Диспетчер устройств → Порты).

### Linux / macOS
```bash
python3 -m esptool --port /dev/ttyUSB0 --baud 115200 --chip esp8266 \
  write_flash --flash_mode qio --flash_freq 40m --flash_size detect \
  0x00000 AziLamp_IR.bin
```

### Если прошивка не стартует
Зажмите **FLASH** → коротко нажмите **RST** → отпустите **FLASH** → запустите скрипт повторно.

После прошивки перезагрузите питание лампы. Сохранённые настройки не стираются.

## Управление

### ИК-пульт

| Кнопка | Действие |
|---|---|
| **OK** | Вкл / Выкл |
| **◀ / ▶** | Предыдущий / следующий эффект |
| **▲ / ▼** | Ярче / тусклее (удержание — плавно) |
| **1** | Заливка (тёплый белый) |
| **2** | Снегопад |
| **3** | Мячики |
| **4** | Радуга |
| **5** | Пейнтбол |
| **6** | Огонь |
| **7** | Матрица |
| **8** | Червячки |
| **9** | Звездопад |
| **0, *, #** | Не назначены |

Расстояние до приёмника: до 2 м. При выключенной лампе работает только **OK**.

### Сенсорная кнопка (центр верхней панели)

| Действие | Результат |
|---|---|
| 1 касание | Вкл / Выкл |
| 2 касания | Смена эффекта |
| Удержание | Яркость ↓ (до выкл), повторное — яркость ↑ |

## 🔧 Диагностика

Если пульт не работает — подключите лампу к ПК и откройте монитор порта (**115200 бод**):

| Сообщение в мониторе | Значение |
|---|---|
| `ИК-приёмник: PIN=14` | ✅ Приёмник инициализирован |
| `ИК: следующий режим` | ✅ Кнопка распознана |
| `IR: неизвестный код 0xFF... NEC` | ⚠️ Пульт работает, код не совпал нужно переделать прошивку |
| `UNKNOWN` | Помехи (солнце, лампы) — игнорируйте |
| Нет сообщений при нажатии | ❌ Проверьте провода и пин подключения |

Сенсорная кнопка продолжает работать даже если ИК-приёмник неисправен.

## Лимит тока

В прошивке задан лимит **800 мА**, но фактическое значение берётся из EEPROM. Если лампа ранее настраивалась через веб-панель — там может быть старое значение. Без Wi-Fi изменить его нельзя. Если нужен гарантированный лимит 800 мА — его можно зашить жёстко.
